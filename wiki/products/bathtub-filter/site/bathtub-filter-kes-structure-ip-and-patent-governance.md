# KES 浴缸过滤器 · IP 与专利治理（内部，非客户页）

## 内部声明

> **本页 `visibility: internal`，不是客户可见页。** 它是「结构 / IP claim」的**内部真理源**——所有结构与专利相关的对外措辞，先在本页对齐，再喂 [宣称台账 claim-register](../bathtub-filter-claim-register.md)。任何对外页（含 D1–D4）里出现专利、FTO、行业首创等措辞，必须与本页「措辞规则表」一致；有冲突以本页为准。

## 一、IP 事实库

### 1. KES 自有 IP

| 项 | 事实 | 状态 |
|---|---|---|
| KES 发明专利 | **1 项 Utility 非临时申请：Modular Terminal Water Treatment System and Method of Use Thereof**（模块化末端水处理系统，含导流/防溅/回洗等结构） | ✅ **已提交、pending，未授权** |
| **申请号 / 申请日** | **App# 19/281,644，申请日 2025-07-26**（确认号 6091 · Docket KESU004 · 发明人 Jiajun Mai + Guoqiang Yan；Yan 已提 age petition 加快审查） | ✅ 已确认（[专利参考页](../bathtub-filter-kes-patent-19-281644-modular-terminal-water-treatment.md)） |
| 对外措辞 | 现可用 `Patent pending`（有申请号背书）；引用时可写 "Patent pending (U.S. App. 19/281,644)" | ✅ 可用；🔴 仍禁 patented/granted/获得专利（是 pending 非授权） |

### 2. 基础料级 IP（自由、非专有）

| 项 | 事实 | 含义 |
|---|---|---|
| CaSO₃ + KDF 去游离氯 | 相关基础专利（Farley/Chlorgon lineage，如 `US5914043A`、`US6056875A`）**2015 已过期**；tub-spout inline（`US6145670A`）、shower-cartridge（`US6096197A`/`US6267887B1`）均已 expired/lapsed | 该化学 + 架构属**公有领域**，KES 可自由采用；🔴 **但不得包装成 KES 专利 / 专利去氯技术** |

出处：[专利表 · legal-status 核验段](../bathtub-filter-patent-table.md)。

### 3. 竞品活跃 IP（route-avoid）

| Patent | 权利人 | 到期 | 与 KES 关系 |
|---|---|---|---|
| **`US12534389B2`** | FilterBaby LLC + Saxton Brothers LLC（授权 2026-01-27） | 2044-03-21 | **faucet** 水过滤器（horizontal + viewable + skincare adapter + UV + smart controller）。KES 是 **tub-spout 竖挂**、无 skincare additive / UV / smart controller → **draft-FTO 判 likely clear**，但**正式 FTO 未做 🟡** |
| `US10159991B2` | Homewerks Worldwide LLC | 2036-08-18 | 分体壳 + 可逆 cartridge，live 架构 claim；route-avoid |
| Farley 个人组合（`US9504940B2` / `US10737203B2` / `US11458487B2`） | David K./Aaron Farley（个人） | 2034–2040 | 均为 shower 相关；route-avoid |

**FilterBaby「45+ 专利」类声称**：🔴 **不得引用**。实际 KES 关注的活跃授权 utility patent 只 **1 项**（`US12534389B2`）。不得转述竞品夸大的专利数量声称。

出处：[FilterBaby FTO 预分析](../bathtub-filter-filterbaby-patent-fto-analysis.md)、[专利表 · live IP 段](../bathtub-filter-patent-table.md)。

### 4. 竞品新品牌 IP 现状

Canopy / Kinder Filter / Tubo **无可见功能型 utility patent**（护城河是品牌/渠道）。Kinder 网站 "patented advanced filtration" 语言**未被可见 filing 佐证**。→ KES 分析竞品时不采信其未证实的专利声称，也不据此贬损。
