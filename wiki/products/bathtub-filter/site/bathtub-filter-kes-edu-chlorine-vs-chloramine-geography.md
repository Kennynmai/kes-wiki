# E1 · 你的城市用游离氯还是氯胺？

## 这一页帮你搞懂什么

你打开水龙头闻到"泳池味"，会以为家家户户的"氯"都一样。其实美国市政自来水用的消毒剂主要分**两种**——**游离氯（free chlorine）**和**氯胺（chloramine）**。它们是不同的化学物质，**过滤难度差很多**，直接影响"哪种过滤器对你有用"。

这一页帮你：
1. 搞懂这两种消毒剂差在哪、地理上怎么分布；
2. 学会**免费查出自己城市用哪种**（ZIP → 水质年报 CCR）；
3. 明白为什么氯胺更难过滤、对选产品意味着什么。

> 口径提醒：这一页是中立科普。有没有氯 / 氯胺是**水的类型问题**，不是"你家水有毒"。我们不吓唬你，只帮你搞清方向。术语不懂随时查 [E4 术语表](./bathtub-filter-kes-edu-water-glossary.md)。

---

## 一、两种消毒剂，差在哪

美国市政水厂给水消毒，主流是两条路线：

| | 游离氯（free chlorine） | 氯胺（chloramine） |
|---|---|---|
| 龙头端主要形态 | HOCl + OCl⁻ | 一氯胺 NH₂Cl |
| 大致覆盖 | 约 60% 的美国大城市 | 约 35–40% 市政系统（超 20% 人口） |
| 味道 | 明显"泳池味" | 味道通常较淡、更闷 |
| 好不好过滤 | **容易**（多种滤材都行） | **难**（要催化炭 / 维生素 C + 足够接触时间） |

数据出处：[消毒剂指南 §1a/§1b](../bathtub-filter-disinfectant-types-and-media-guide.md)、[北美水质分析 §1.1](../bathtub-filter-na-water-profile-and-target-market-analysis.md)。

**为什么水厂要用氯胺？** 不是因为它"更毒"，而是氯胺在管网里更稳定、衰减更慢，能维持更长距离的消毒余量，还能减少消毒副产物（DBPs，见 [E4](./bathtub-filter-kes-edu-water-glossary.md)）。代价是：**终端过滤器更难去除它**（[消毒剂指南 §1b](../bathtub-filter-disinfectant-types-and-media-guide.md)）。

## 二、地理上怎么分布（用你能认得的城市）

按美国 top 100 城市抽样，大致是 60% 游离氯 / 40% 氯胺（[城市速查表 §1](../bathtub-filter-utility-service-map-by-metro.md)）。下面是源文件里点过名的城市——**只列有据可查的，没提到的城市请自己查 CCR，别对号入座**。

### 用游离氯的城市（举例）

纽约、芝加哥、亚特兰大、拉斯维加斯、凤凰城、圣安东尼奥、埃尔帕索、杰克逊维尔、孟菲斯、匹兹堡、巴尔的摩、纳什维尔、萨克拉门托、西雅图、波特兰、火奴鲁鲁、底特律等（[城市速查表 §2.1](../bathtub-filter-utility-service-map-by-metro.md)）。

### 用氯胺的城市（举例）

洛杉矶、旧金山 / 奥克兰 / 圣何塞、圣地亚哥、休斯顿、达拉斯 / 沃斯堡、丹佛、费城、华盛顿特区、波士顿、迈阿密 / 坦帕、明尼阿波利斯、密尔沃基、新奥尔良、圣路易斯、印第安纳波利斯等（[城市速查表 §2.2](../bathtub-filter-utility-service-map-by-metro.md)）。

### 🟡 会变化的城市（别做长期假设）

- **洛杉矶正在从游离氯逐步过渡到氯胺**（LADWP 计划 2027–2029 完成，会逐区漂移）（[城市速查表 §4](../bathtub-filter-utility-service-map-by-metro.md)）。
- 约 **25–40% 的氯胺城市每年会临时切换回游离氯几周**（通常春季、持续 2–8 周，用于管网冲洗）——切换期你可能突然闻到"泳池味"（[消毒剂指南 §3](../bathtub-filter-disinfectant-types-and-media-guide.md)）。已知例子：DC Water（每年约 3–5 月）、格林斯博罗（NC）、德州部分城市。

> 所以：**城市名单会过时。真正靠谱的办法是自己查一次**——下面教你。

## 三、怎么查自己城市用哪种（免费、10 分钟）

最权威的办法不是闻味道，也不是试纸，而是查你水务公司的**年度水质报告（CCR，Consumer Confidence Report）**——这是 EPA 规定每家市政水务每年要向消费者公布的报告（[机构指南 §1](../bathtub-filter-institutional-guidance.md)）。

**三步走：**

1. **知道你的水务公司是谁**：你的自来水账单上有；或用 ZIP / 地址在网上搜 "你的城市 + water CCR" / "你的城市 + Consumer Confidence Report"。
2. **打开 CCR**，找"disinfectant / disinfection"相关段落——写着 chlorine 的是游离氯，写着 chloramine / chloramines 的是氯胺。
3. **交叉核对**：也可以对照 [KES 城市速查表](../bathtub-filter-utility-service-map-by-metro.md) 看你城市在不在名单里。

> 详细的"CCR 长什么样、去哪几项看"，见 [E7 怎么读你的 CCR](./bathtub-filter-kes-edu-how-to-read-your-ccr.md)。

**家庭试纸能不能判类型？** 只能当**辅助线索**：用游离氯 + 总氯双垫试纸，如果**总氯远大于游离氯**，说明很可能有氯胺（总氯 − 游离氯 = 结合氯 ≈ 氯胺）。但**这个减法会放大误差，只作 flag，类型还是以 CCR 为准**（[自测套件 §二](../bathtub-filter-kes-water-diagnosis-kit-and-modular-acquisition-engine.md)）。怎么测见 [E5](./bathtub-filter-kes-edu-how-to-test-your-water.md)。

## 四、为什么氯胺更难过滤（这才是关键）

同样是"氯"，去除难度差一个量级：

| 滤材 | 游离氯 | 一氯胺（氯胺） |
|---|---|---|
| 标准活性炭（GAC） | ✅ 优秀 | ⚠️ 差至中等（需 3–4 倍接触时间） |
| 催化活性炭 | ✅ 优秀 | ✅ 较好至优秀（专为氯胺改性） |
| 亚硫酸钙（CaSO₃） | ✅ 优秀 | ❌ 无效 |
| KDF-55 | ✅ 优秀 | ❌ 无效（实测 18.2%） |
| KDF-85 | ✅ 优秀 | ❌ 无效（实测 1.4%） |
| 维生素 C（抗坏血酸 / 抗坏血酸钠） | ✅ 极速 | ✅ 有效，但需 4+ 分钟接触 |

出处：[消毒剂指南 §2](../bathtub-filter-disinfectant-types-and-media-guide.md)。

**为什么难？** 一氯胺的 N–Cl 键难被还原、氧化势低。去除它需要**更长接触时间**——维生素 C 与一氯胺的反应半衰期约 **4 分钟**（[消毒剂指南 §2](../bathtub-filter-disinfectant-types-and-media-guide.md)）。

**这就是浴缸 vs 淋浴的结构差别**：淋浴过滤器接触时间 <1 秒，来不及反应氯胺；而浴缸注水会停留几分钟，给了维生素 C / 催化炭反应的时间窗口（[消毒剂指南 §2](../bathtub-filter-disinfectant-types-and-media-guide.md)）。

### 对选产品意味着什么（诚实边界）

- **你在游离氯城市** → 普通去氯滤材（含 KES V1 的 KDF55 + 亚硫酸钙）就适用。看 [S1 游离氯场景页](./bathtub-filter-kes-scenario-free-chlorine.md)。
- **你在氯胺城市** → 🔴 **不要买只标"removes chlorine"却没说氯胺的产品**——很可能对你的水无效。你需要催化炭 / 维生素 C 且接受"缸内多等几分钟"的方案。看 [S2 氯胺场景页](./bathtub-filter-kes-scenario-chloramine.md)。

## 诚实边界 / 护栏

- 用游离氯还是氯胺，是你**当地水厂的消毒策略**，不代表哪种水"更脏"或"有毒"。两种都符合 EPA 规范。
- 城市名单**会过时**（LA 正在过渡、氯胺城市季节性切换）——认准 CCR，别只信名单。
- 🔴 不把"你城市用氯胺"说成健康威胁；🔴 不暗示某产品能保护你健康 / 改善皮肤。这一页只帮你分类型、选对工具方向。
