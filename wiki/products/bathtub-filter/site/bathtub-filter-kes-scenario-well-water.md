# 场景页 · 井水（低中度铁 / H₂S 气味 · nuisance 舒适线）

> 本页按内容地图五段模板：① problem → ② 配置（链 M 页）→ ③ 有界 claim → ④ 承重护栏 → ⑤ 诚实劝退。滤材 claim 的唯一口径在对应 M 页，本页只引用不改写（见 [内容地图 §四](./bathtub-filter-kes-marketing-site-content-map.md)）。

## ① Problem — 井水的浴缸痛点是什么

私人井水通常**不加氯 / 不加氯胺**，所以浴缸痛点不是消毒剂，而是（[井水研究 Task 2–3](../bathtub-filter-well-water-research.md)）：

- **铁 / 铁锈**：橘锈色染缸、染龙头、金属味；
- **硫化氢（H₂S）**：「臭鸡蛋味」，泡澡体验差；
- **部分颗粒 / 沉积物**。

这是 **nuisance（气味 / 锈渍舒适）级** 问题，不是 health-grade remediation。市政线的 CaSO₃ / KDF55 在这里错位——井水线要换成 KDF85 主导。

## ② 配置（真理源 = M 页）

**粗 PP → KDF85 → 催化炭**（[media-stack §方案 C](../bathtub-filter-kes-media-stack-options-by-water-type.md)）：

| 层 | 角色 | 真理源 M 页 |
|---|---|---|
| 粗规格前置沉积层 | 先截锈渣 / 颗粒，减少主媒体过快堵塞 | [M7 · 过滤棉（PET）](./bathtub-filter-kes-media-pp-cotton.md) |
| KDF85 | **主力去铁 / 去 H₂S / 部分锰**（well-water 主 KPI） | [M5 · KDF85](./bathtub-filter-kes-media-kdf85.md) |
| 催化炭 | 气味 / 有机物 polish，井水 sensory finish | [M3 · 催化活性炭](./bathtub-filter-kes-media-catalytic-carbon.md) |

## ④ 承重护栏 / disclaim

- 覆盖口径统一 **low-to-moderate（低中度）**，不得升级为「treats well water」。
- **禁**杀菌 / 除砷 / 硝酸盐 / 铀 / 高铁全屋替代 / 软化——见 [M5 承重护栏](./bathtub-filter-kes-media-kdf85.md)。
- 定位是 **first step / nuisance 舒适**，不是全屋净化替代；用户仍应按 CDC / EPA 建议自测井水（[井水研究 Task 5](../bathtub-filter-well-water-research.md)）。
- 寿命 / 更换用 baths / gallons，不用 months（口径见 [T3 更换/寿命](./bathtub-filter-kes-page-replacement-and-lifespan.md)）。

> **验证与口径**：验证 / 认证口径见 [T2 我们怎么测/认证](./bathtub-filter-kes-page-how-we-test-and-certify.md)，更换 / 寿命见 [T3 更换/寿命](./bathtub-filter-kes-page-replacement-and-lifespan.md)。

## ⑤ 诚实劝退（能力外明说 + 留邮箱）

明确写给能力外用户，不卖错：

- **高铁 / 高硫（约 >2–3 ppm）**：compact bath filter 会数天到数周即堵、压降剧增、差评——**明说不适合**，建议走全屋 backwashing / AIO 系统（[井水研究 Task 4](../bathtub-filter-well-water-research.md)）。
- **健康级污染物（砷 / 硝酸盐 / 铀 / 细菌）**：本产品**不治**，需全屋 RO / 专材，先按 CDC 建议自测。
- **硬水 / 想软化**：本产品**不软化**；真软化走 [Route B 独立 SKU](../bathtub-filter-point-of-use-hardness-softening-feasibility.md)，或看 [S4 硬水 / 水垢场景](./bathtub-filter-kes-scenario-hard-water-scale.md)。
- 能力外一律：**「这不适合你家的水 — 留个邮箱，合适的方案上线我们通知你。」**
