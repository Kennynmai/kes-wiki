# P2 · KES V1 套装内容规格页（Pack-contents spec）

## 这一页是什么

这是 KES 浴缸过滤器 **V1（游离氯版）套装内容的正式清单**，供 PDP / 说明书 / 包装标签 / 客服统一引用。每项**数量 / 规格如实**，缺的标 🟡（待供应链 / BOM 确认），**不杜撰**。

来源三处：一手 [讲解件 §配件赠品 + §3 结构](../../../../raw/products/bathtub-filter/2026-06-18-desktop-source-folder-import/source-files/浴缸过滤器_城市市政自来水版202602讲解.md)、已消化的 [卖点与套装内容页 §8](../bathtub-filter-kes-v1-selling-points-and-pack-contents.md)、以及挂带适配的 [结构页](./bathtub-filter-kes-structure-flat-strap-fit.md)。护栏照 [claim-register](../bathtub-filter-claim-register.md)。

> **溯源说明**：讲解件「配件赠品」节只写了「余氯测试试纸 / 过滤棉20块 / 悬挂绑带」三项（**试纸与挂带无具体数量**）。更细的数量 / 尺寸来自卖点页 §8。**凡两处不一致或某处无数字的，见下表「溯源 / 分歧」列并标 🟡。**

## 四、护栏（本页承重红线）

- 🔴 **不得杜撰数量 / 规格**。任何未在讲解件或卖点页出现的数字一律标 🟡，不进包装标签 / PDP 硬 spec。
- 🟢 **试纸 = 游离氯验证工具**，说明「用游离氯试纸做过滤前后对比；不要用 TDS 笔当裁判」（register Verification-by-user；🔴 TDS 笔 / 铅试纸不作验证或卖点）。
- 🟢 **3M 挂钩 / 短硅胶带 = 辅助固定**，主固定力来自硅胶带拉力 + 摩擦；**每条兼容表达必带「不支持」边界**（swan-neck / 短出水嘴需 workaround，见 [[bathtub-filter-supported-spout-matrix]]）。🔴 禁 universal fit。
- 🔴 浴盐 / 阻垢仓不得写成「软化水」；阻垢 TDS 可能上升，「不软化」承重句随行。
