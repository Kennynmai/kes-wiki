# 来源摘要｜氯胺T 实测报告评估（2026-10-15）

## 结论先行

> **这份报告不能证明滤芯有任何氯胺去除能力。而且它测的**很可能不是市政水里的氯胺（一氯胺 NH₂Cl）**。**

用户的任务是「评估过滤氯胺的有效程度」。诚实答案是：**这个数据集无法算出去除率，而且对象可能就搞错了。**

三句话版本：

1. **读数不降反升**（0.5~1 → 1 ppm，随累计水量上升）——没有任何净去除的证据。
2. **试剂物种错了**：投加的是**氯胺 T**（固体缓释消毒剂，在水中水解释放**次氯酸**），不是**一氯胺 NH₂Cl**（市政水真实结合氯）。这份测试大概率在测亚硫酸钙对**游离氯**的去除——而那件事 KES 早在 2026-03-20 就测过（84–90% 去氯率）。两组数据互相冲突。
3. **方法学不成立**：无介质牌号、无配对进水对照、无 pH、游离氯从未单独测；且五张照片光照不一致（同一标准色块跨图差异量级远大于同图相邻色阶差，具体数值已撤回），趋势本身不可读。

## 2）核心发现：氯胺 T ≠ 一氯胺

| | 氯胺 T（Chloramine-T） | 一氯胺（Monochloramine） |
|---|---|---|
| CAS | 127-65-1（无水盐；三水合物 7080-50-4） | 10599-90-3 |
| 化学式 | C₇H₇ClNNaO₂S（MW 227.64） | NH₂Cl（MW 51.47） |
| 本质 | N-氯对甲苯磺酰胺钠：**固体有机氯胺衍生物** | 氯 + 氨反应生成的水中氯胺 |
| 水中行为 | 溶于水后**水解生成次氯酸 HOCl / 次氯酸根**（反应性与次氯酸钠相近），以有效氯形式缓释 | 本身即配水系统真实结合氯 |
| 水溶液 pH | **弱碱性：pH 通常约 8.5** | 随配水条件 |
| 用途 | 医疗 / 器械表面消毒；饮用水与泳池消毒属供应商与行业口径 | 市政水二次消毒 |

> 西班牙语维基《Cloraminas》条目的实际表述：*«La Cloramina-T se denomina cloramina, pero es realmente una sal (CH₃C₆H₄SO₂NClNa) derivada de una cloramina.»*

> ⚠️ **2026-10-28 表述口径更正（本摘要第 2 节）**
> - **引语无法归属**：原引西语维基「*no debe ser confundida con monocloramina*」一句，在 es.wikipedia 中检索不到（`insource` 检索 0 命中；全网精确短语检索 0 命中）→ 已删除并替换为上句。
> - **pH 区间**：原写「8–10（碱性）」。en.wikipedia 原文为 "slightly basic (**pH typically 8.5**)"；「8–10」出自中文科普二级来源，未核到原文 → 改为 pH ≈ 8.5。
> - **CAS 与分子式**已核到一手登记（PubChem CID 3641960 / CID 25423）。
> - **「3 个独立来源交叉确认」的说法被夸大**：实际是 1 个英文维基 + 1 个中文科普二级来源 + 2 个镜像/AI 百科（11467、grokipedia）。**物种身份这一结论本身不变**（氯胺 T ≠ 一氯胺），但「交叉确认」的措辞不成立。
> - 复核记录见 [[bathtub-filter-disinfectant-types-and-media-guide]] §1b-bis。

**推论**：在 19 L/min、29 °C 水流中，氯胺 T 实际走的是「缓释 → HOCl → 被亚硫酸钙快速还原」这条路径。**这测的是游离氯去除，不是氯胺去除。**

而亚硫酸钙对游离氯的有效性 KES 已自测过：2026-03-20，5 ppm 游离氯、16.5–30 L/min、**去氯率 84–90%**（[[bathtub-filter-25lpm-dechlorination-bench-test-spec]]）。

**本报告在 19 L/min 测得「无下降」，与已知游离氯性能直接冲突。** 两种解释都指向报告不可用：

| 可能 | 含义 |
|---|---|
| (a) 挑战液主要含 HOCl，滤芯理应打到接近 0 | 实际读数 1 ppm → **装置旁通 / 取样错误 / 读数错误** |
| (b) 读数反映氯胺 T 分解产物残留，与 NH₂Cl 无关 | 对氯胺**零信息量** |

同一封消息里的三条自述：

> "实话我们是没有用第三方机构去测试'氯胺、游离氯'的寿命和过滤率的……"

>
> "这个过滤率我也只能**用自己的视觉感官**去做，因为显色有轻微差异是看不出的"

**由此可确认的四件事**

| # | 事实 | 对本报告的意义 |
|---|---|---|
| 1 | 试剂 = **氯胺 T**（执行人自述） | 「本次测的是游离氯而非氯胺」**不再是"仅基于试剂身份的推断"，而是执行人书面确认** |
| 2 | 挑战液 = **1 吨自来水 + 氯胺 T 配至 2 ppm**（自来水总氯 0.1 ppm） | 投加后实测只有 0.5–1 ppm，**投加本身未达标称**，差额会被算进"去除"里（见下） |
| 3 | 测定方法 = **只有总氯**，无物种特异性方法、无一氯胺标液 | 读数**在原理上无法区分** HOCl 与 NH₂Cl；本方法不可能产出氯胺去除证据 |
| 4 | 读数 = **目视显色**（"显色有轻微差异是看不出的"） | 精度上限极低；"无下降"只能作**弱否定信号**，不能作定量证据 |

### ⚠️ 新发现：产物—结论冲突 —— 执行者结论「过滤效率 50%」与报告自身读数矛盾

执行人 2026-10-14 11:17 的结论原文：

> "测试了1吨水，2PPM氯胺，在19L/min，和29℃水温情况下，**过滤效率为50%**"

但报告自身的读数是「初始 0.5~1 ppm → 178 L 0.5–1 → 356 L / 712 L / 1068 L 全部 1 ppm」，**全程无下降**。**产物与结论互相矛盾。**

最可能的解释（**推断，待操作者确认**）：50% 是拿**标称 2 ppm** 与实测余量相减得到的；而**首个读数在进入滤芯前后就已经是 0.5–1 ppm**（自来水 0.1 ppm + 标称 2 ppm 投加 → 实测只有 0.5–1），差额里混着"投加没达到标称"与"加标液自降解"，被一并计成了"过滤效率"。**这正是"缺配对进水对照"的典型后果。**

> **本工单剩余项（必须向操作者确认）**：50% 的计算基准是**标称 2 ppm** 还是**实测进水**？若答案是"标称"，则**该数据集里没有任何一个点具备去除率含义**。

### 对产品与包装侧的影响（不要误用）

执行人基于本次数据建议："我建议是宣称游离氯 FREE CHLORINE，包装物料也是这样讲述……试纸也只做 游离氯测试试纸"。

### 3.1 跨图不可比（⚠️ 2026-10-15 晚间自查后降级）

**可保留的定性结论**：五张照片分别在室内灯、室外阴影、直射日光下拍摄，且色卡有明显透视 → **照片比色数据不得跨图比较**。报告里「0.5~1 → 1 ppm」的上升趋势**很可能只是光照差异**。这一点不需要精确数字支撑——五张照片并置即可判断。

### 3.2 色卡分辨率不足

级别 0.1 / 0.2 / 0.5 / 1 / 2 / 5 / 10 mg/L——**0.1–1 ppm 挤了四级**。Lab 最近邻反推值波动大（具体数值已撤回，见 raw 归档），与报告标注不一致。

> ⚠️ **口径标注（2026-10-15 晚间降级）**：ROI 为目视标定，逐点估计值**不可引用**。原判断「跨图同色块差值稳健、不依赖 ROI」经自查**不成立**——见下方自查修正记录。可保留的只有一条结构性事实：**色卡在 0.1–1 ppm 区间分辨率不足**（0.1/0.2/0.5/1 四级挤在一起），这不依赖任何像素计算。

#### 自查修正记录（2026-10-15 19:20，作者自查）

作者在复核本节时重做了色卡检测，发现**原采样存在系统性缺陷，原「稳健」标注是错误的**：

1. **p2_2 的色卡 ROI 落在手的阴影里** → 该组最大差值主要反映阴影几何，不是「白平衡不一致」。
2. **色块是倾斜的平行四边形**（卡片有透视），而采样框是固定矩形 → 固定 x 带随 y 漂移出块外。切图肉眼复核（712L 色卡条带）确认色卡本身单调干净，**是采样框错了**。
3. **采样 y 带跨到色块下方的数字标签**（黑字拉低 L*）→ 造成「阶梯非单调」的假象。
4. **重做 v2/v3 两版修正均失败**：v2 全部 5 张图阶梯非单调（含肉眼最清晰的 712L）；v3 掩膜本身有效（63,245 像素）但**分组只得到 4 组而非 7 组**——透视倾斜使相邻色块在列投影上连成一片，**这是照片比色的根本困难，不是可修复的 bug**。

**唯一的量级对比仍然成立**（在肉眼最清晰的 712L 图上测得）：**跨图同一色块的亮度差异，量级上大于同图内相邻色块之间的差异（约大一个量级）**。数值本身已撤回（ROI 标定有误）。

**跨图扰动比同图相邻色阶差大一个量级 → 跨图比色的误差远大于被测量本身，趋势不可读。** 这条量级关系是结论的真正依据；**具体数值不应引用**（ROI 标定有误）。

**降级后仍然成立的定性结论**：五张照片分别在室内灯、室外阴影、直射日光下拍摄，且卡片有明显透视。**照片比色数据不得跨图比较**，这一点不需要精确数字支撑——五张照片摆在一起看就足以判断。

### 3.3 标称 2 ppm vs 初始读数 0.5–1 ppm

相差 2–4 倍。解释互斥且未记录：2 ppm 是储备液经稀释／判读不可靠／挑战液已降解。**结果：无论哪种，都算不出有意义的去除率**（五点若全为出水 → 缺配对进水；若「初始」是进水 → 与标称矛盾）。

### 3.4 工况证明力极弱

| 项 | 数值 |
|---|---|

| EBCT（假设 CaSO₃ 130 g，密度 0.9–1.1 g/cm³）| **0.37–0.46 s** |

对照 [[bathtub-filter-chloramine-media-research]] §2：**固相催化炭除氯胺需 EBCT ≥ 4–5 min（240–300 s）**。

**本次 EBCT ≈ 0.4 s，约为门槛的 1/600–1/800。** 即使用活性最高的介质，此工况也天然倾向「无净去除」。这是**证明力弱的工况选择**，不是对滤芯的有效检验。

## 6）这次真正改变了什么

### 变了：新增一条方法学教训（此前 wiki 未覆盖）

**加标试剂的物种身份必须在投加前书面确认。**

「氯胺 T」与「一氯胺」在中文语境下极易混淆，但它们测的是两件完全不同的事。2026-10-09 那次测试的挑战液口径未写明，2026-10-15 这次明确写了是氯胺 T —— 这意味着**10-09 那次可能也用了同一个试剂**，若如此，那次「接近 0」的结果需要**重新审视**：它可能是游离氯去除，而非氯胺去除。

这条教训已写入 [[bathtub-filter-validation-testing-protocol]] Module 7 的测试设计清单。

### 变了：矛盾事件的证据基础进一步恶化

## 7）建议下一步

1. **先定物种**：投加前书面确认 CAS 与物种。目标若是市政水氯胺，应用**一氯胺标准液**，或次氯酸+氨按 Cl₂:NH₃-N = 4.5:1~5:1 现场配比，并**立即测 pH**。
2. **必须配衰减空白**：同批挑战水介质留空，时间/温度配对同步采样。没有这一条，测多少遍都无法归因。
3. **改用 DPD 分光法**（或 Hach 等效），弃用色卡；同时分测**游离氯**与**总氯**，差值估结合氯。
4. **提高进水浓度**至 5–10 ppm 进入有效区间，并配惰性介质水力空白。
5. **氯离子质量平衡**（2026-10-09 已解锁）：测**产物**而非底物，免疫于衰减混淆——仍是定案手段。
6. **EBCT 正面回答**：若走催化炭路线，0.4 s 天然不够。这不是测试能修的，是**架构问题**——需要浸没式/浸泡件设计，而非 inline 挂篮。
