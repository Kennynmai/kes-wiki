# 特殊水源：RO / 小型社区供水 / 雨水收集，KES 适不适合你

> 消费者水质科普簇（Spoke E · SPECIAL）。这是一页**教育页 + 诚实边界页**。基调：知情、不恐吓、能力外主动劝退。所有数据来自 [北美特殊水源场景分析](../bathtub-filter-north-america-special-water-sources.md) 与 [井水完整研究](../bathtub-filter-well-water-research.md)，不外推、不杜撰。

## 这页帮你搞懂什么

- 除了市政自来水和井水，北美还有几种"特殊水源"——你可能就是其中之一 🟢
- 每种水源的特点，以及 **KES 对你有没有价值** 🟢
- 家里已装**软水器 / 前置过滤 / 全屋活性炭**，还需不需要浴缸端（§六 三分岔）🟢
- 一个诚实提醒：**如果你已经装了 RO，KES 对你多半没价值**，我们直接说 🔴
- 我们能管什么、不能管什么，边界说在前面 🟢

想先搞清"我家水到底属于哪一类" → 先看 [水质自测与诊断页](./bathtub-filter-kes-page-water-test-diagnosis.md)。

## 一、先说最重要的诚实提醒：RO 用户，我们对你多半没价值 🔴

如果你家已经装了**反渗透（RO）系统**（无论是水槽下的还是全屋的），有一件事要先说清楚：

> **RO 出来的水通常已经把氯（以及大部分溶解物）去掉了。KES 是一个"注水阶段去游离氯"的舒适滤芯——你的水里已经没多少氯了，我们对你多半没有价值。** 🔴

这是我们主动劝退的地方：**不卖错，是我们的信任资产。** 与其让你买回去发现试纸测不出差别，不如现在就告诉你——你的水源已经不需要我们了。

（顺带一提：如果你关心的是 PFAS，RO 本来就是处理 PFAS 的正确路线之一，浴缸炭滤芯做不到——详见 [PFAS 与浴缸过滤器页](./bathtub-filter-kes-edu-pfas-and-bath-filters.md)。）

## 二、小型社区供水系统（SCWS）：像"井水 + 市政水"的混合体

美国除了大城市市政水和私人井水，还有一类**小型社区供水系统（Small Community Water Systems, SCWS）**：🟢

- 约 **15 万个**系统，服务约 **4,500 万人**（约占美国人口 14%），主要在农村、郊区、小镇。🟢
- 消毒剂分布：约 **70% 用氯**、约 **20% 用氯胺**、约 **10% 用 UV / 臭氧**——和市政水类似。🟢

**特点是"水质波动大"**：小型系统预算有限、处理未必稳定，硬度、消毒剂浓度可能今天一个样明天一个样，老旧管道还可能带来铁、锰、铅。🟢

**KES 适不适合你？**

| 你的 SCWS 情况 | KES 适配 | 说明 |
|---|---|---|
| 用**氯**消毒 | ✅ 适合 | 和市政游离氯市场一样——这是我们的主场景 |
| 用**氯胺**消毒 | ⚠️ 看版本 | V1（游离氯配置）对氯胺基本无效；氯胺需要 V1.5 配置，[claim 台账](../bathtub-filter-claim-register.md) 有界 |
| 水**极硬** | ❌ 不软化 | 见下方"软化"说明——我们只提供阻垢选项，不做软化 |
| 含**铅 / 铁 / 砷等** | ❌ 不认领 | 这些需要专门的媒体或全屋系统，我们不认领 |

> 因为 SCWS 水质波动，**先测一次你家的水**（类型看 ZIP→CCR，浓度/硬度用试纸粗筛）比什么都重要 → [水质自测与诊断页](./bathtub-filter-kes-page-water-test-diagnosis.md)。🟢

## 三、雨水收集：软水、但偏酸、可能有细菌

如果你用**雨水收集系统**（美国约 35 个州合法，约 50–100 万户）：🟢

| 参数 | 雨水典型情况 | 意味着 |
|---|---|---|
| 硬度 | 约 0–50 ppm（极软）| **不需要软化**——雨水本来就软 |
| pH | 约 5.0–6.5（偏酸）| 偏酸的水会腐蚀管件、浸出金属，**需要 pH 中和**（如方解石类媒体）|
| 污染物 | 鸟粪、屋顶杂质、灰尘 | 需要过滤 |
| 细菌 | 可能含大肠杆菌等 | **可能需要杀菌** |
| 消毒剂 | 通常没有（除非你自己加氯）| 如果你自己加了氯，KES 的去氯才用得上 |

**KES 适不适合你？**

- 雨水的核心需求是 **pH 中和 + 过滤杂质 +（可能）杀菌**——这些**都不是** KES 的能力。🔴
- 只有当你**自己往雨水里加了氯**时，KES 的去游离氯能力才有部分用武之地。🟢
- 🔴 我们**不认领**：pH 调节、杀菌 / 消毒、除细菌。这些请找专门方案。

## 四、其它特殊水源（简表）

取自 [北美特殊水源场景分析](../bathtub-filter-north-america-special-water-sources.md)：🟢

| 水源 | 规模 | KES 适配 | 备注 |
|---|---|---|---|
| **度假屋 / 第二住宅** | ~550 万套 | ⚠️ 看水源 | 若是用氯的市政水，去氯适用；长期空置后首次用水质差是另一类问题，我们不认领"启动冲洗 / 杀菌" |
| **移动房屋 / 房车** | ~300 万套 | ⚠️ 看水源 | 若是用氯的市政水，去氯适用；房车 center-set 龙头已有实测适配样本（见安装页）|
| **高 TDS 地区**（西南部）| ~1,000–1,500 万人 | ❌ 不适合 | TDS 高、可能含砷/氟——需要 RO / 全套方案，**我们不认领降 TDS** |
| **海水淡化水** | ~500–800 万人 | ❌ 不适合 | 需 RO 系统，超出我们范围 |

## 五、关于"硬水软化"：我们只做阻垢，不做软化 🔴

无论是 SCWS 的极硬水、还是任何硬水地区，都要说清楚一条**本轮明确的决策**：

> **KES 这个产品不做软化。** 紧凑型浴缸滤芯**做不到**有实际意义的软化。对硬水，我们**只提供阻垢剂（anti-scale）选项**——它帮助保护你的浴缸和五金件减少水垢结垢，但**它不软化你的水、不降低硬度**。🔴

- 🔴 我们**不会**暗示 KES 有、或将有软化产品；也**不做**"软化版留邮箱"这种承诺。
- **真正的软化**属于**全屋软水器**这个独立品类——那不是我们。要软化，请找全屋软水器。我们诚实指出，就到这里。🔴
- 阻垢和软化的区别、以及"TDS 笔测不出变化=正常"（因为我们本就没在软化）等口径，见 [claim 台账](../bathtub-filter-claim-register.md)。

## 六、家里已装全屋系统？（软水器 / 前置过滤 / 全屋活性炭）

「我家已经装了全屋处理，还需要浴缸端的吗？」——答案取决于你装的是**哪一种**。三种系统干的是三件不同的事：🟢

### 6.1 软水器 → ✅ 仍需要（如果你在意氯）

- 软水器是**离子交换**：只把钙镁（硬度）换成钠/钾，**对氯的去除约等于零——氯 100% 通过软水器**。🟢
- 所以"水已经软了"和"水里还有氯"完全可以同时成立。软水器家庭是我们的正常场景之一，完整解释见 [软水器家庭页](./bathtub-filter-kes-edu-water-softener-households.md)。
- 这不是软水器的缺陷——它本来就不是为去氯设计的。🟢

### 6.2 前置过滤（沉积 PP）→ ✅ 仍需要（如果你在意氯）

- 沉积前置只**物理拦截颗粒**（泥沙、铁锈渣）；氯是**溶解态**，直接穿过滤棉。**你的前置管颗粒，氯还在。** 🟢
- KES 的 PP 层与你的前置不冲突——一个管入户颗粒，一个管注水末端。

### 6.3 全屋活性炭 → ⚠️ 先测再说（我们可能对你没价值）

全屋活性炭系统（whole-house carbon）**本来就是去氯的**——它正常工作时，你龙头出来的水已经基本无氯。所以：

> **先用试纸测你的龙头水，再决定。**
> - 试纸测不出氯 → 你的全屋炭还在工作，**你不需要我们**——别买。🔴
> - 试纸测出氯 → 你的炭床可能已经**穿透（耗尽）**，正确动作是**换全屋炭床**——或在换床前后加一个末端把关。

为什么值得测一次：炭床是消耗品，而且**静默失效**——耗尽时外观无变化、系统无提示、水看起来一切照旧。试纸是最便捷的自查方式（怎么测见 [水质自测与诊断页](./bathtub-filter-kes-page-water-test-diagnosis.md) / [怎么测洗澡水](./bathtub-filter-kes-edu-how-to-test-your-water.md)）。🟢

- 🔴 我们**不会**说"全屋炭不可靠，所以你需要我们"——它工作时你确实不需要末端；我们只提醒：它需要被验证，而它自己不会告诉你。

**三分岔速查：**

| 你家已装 | 它管什么 | 氯呢 | KES 对你 |
|---|---|---|---|
| 软水器 | 换掉钙镁（硬度） | 100% 通过 | ✅ 仍有价值（去氯） |
| 前置过滤（沉积 PP） | 拦颗粒 / 泥沙 | 溶解态，直接通过 | ✅ 仍有价值（去氯） |
| 全屋活性炭 | 去氯（工作时） | 工作时已去掉；**穿透后回来，且无提示** | ⚠️ 先测：测不出氯=不需要我们；测出氯=先考虑换炭床 |

## 七、护栏总表：我们不说什么

| 我们**不会**说 | 为什么 |
|--------------|--------|
| "适合所有水源 / 净化任何水" | 🔴 每种水源需求不同，很多不是我们能力范围 |
| "软化你的（硬 / 井 / SCWS）水" | 🔴 不做软化——只提供阻垢选项；软化=全屋软水器（非我们）|
| "去 PFAS / 除砷 / 除氟 / 降 TDS" | 🔴 需 RO / 专项媒体，我们不认领 |
| "杀菌 / 消毒 / 让雨水安全饮用" | 🔴 不是消毒设备，不认领 |
| "你的（特殊水源）水有毒 / 危险" | 🔴 不做 toxin-panic 恐吓；只说水的类型和产品适配 |
| 对 RO 用户暗示"你也需要一个" | 🔴 RO 已去氯，我们对你多半没价值——主动劝退 |
| 对全屋活性炭用户硬卖"再加一层更安心" | 🔴 炭床工作时末端确实不需要；只教「先测再决定」，不制造焦虑（§六） |

**核心态度**：不是"你的水更差"，而是**"先知道你家的水属于哪一类，风险类型不同、工具也不同"**。能力外的（软化、杀菌、除砷、降 TDS、PFAS），我们会诚实劝你去找对的方案。
