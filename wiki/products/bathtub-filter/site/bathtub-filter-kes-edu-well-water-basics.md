# 井水必读：美国井水常见问题 + 为什么它跟自来水不一样

> 消费者水质科普簇（Spoke E · E2）。这是一页**教育页**，不是产品功效页。基调：知情、平衡、不恐吓、说清不确定性。所有数字来自[井水完整研究](../bathtub-filter-well-water-research.md)与[特殊水源分析](../bathtub-filter-north-america-special-water-sources.md)，不外推。

## 这页帮你搞懂什么

- 美国有多少家庭在用井水，井水跟市政自来水到底哪里不一样 🟢
- 井水常见的问题分几类——哪些是"闻得到看得到"的舒适问题，哪些是"没味道没颜色"的健康问题 🟢
- 什么时候你**应该找专业机构做一次水质检测**，而不是靠一个浴缸滤芯解决 🟢
- KES 浴缸滤芯对井水**能做什么、不能做什么**——我们把边界说在前面 🟢

如果你想先搞清"我家水到底属于哪一类"，先看 → [水质自测与诊断页](./bathtub-filter-kes-page-water-test-diagnosis.md)。

## 一、井水在美国有多普遍

- 约 **2,300 万**美国家庭用私人井水，覆盖约 **4,300 万人**（约占美国人口 15%，即约"每 8 个美国人里有 1 个"）🟢
- 井水集中在**农村到城郊**地带，而不是密集城市中心 🟢
- 地理上比较集中的地方：新英格兰走廊（缅因、新罕布什尔、佛蒙特、纽约）、五大湖 / 中西部上游（密歇根尤其突出）、卡罗来纳与北佛罗里达 🟢
- **缅因州**是个典型例子：该州一半以上人口的饮用水来自私人井 🟢

一句话记住：**井水用户往往"早就知道自己的水跟城里不一样"**——因为很多问题是看得到、闻得到的。这跟市政供水用户很不同。

## 二、为什么井水跟市政自来水不是一回事

最根本的一点：

> 市政自来水的核心问题是**加进去的消毒剂**（游离氯，或部分城市的氯胺）。
> 井水**没有任何添加的消毒剂**——它的问题来自地质和周边环境，完全是另一套。🟢

| 维度 | 市政自来水 | 私人井水 |
|------|-----------|---------|
| 主要消毒剂问题 | 游离氯（多数城市）或氯胺 | **无**——没有添加消毒剂 |
| 铁 / 锰 | 市政层面已处理，很少成问题 | 主要的感官问题；区域研究显示 32–57% 的井水超过 SMCL |
| 硬度 | 各地不一 | 地下水通常比地表水更硬 |
| 硫化氢（臭鸡蛋味）| 市政管网极少见 | 约 20% 的井水季节性出现，取决于地质 |
| 细菌 | 被氯消毒杀灭 | 真实存在的风险（马里兰研究：25.4% 的井检出总大肠菌群）|
| 砷 | 市政系统受监管并处理 | 全国约 7% 的井超标；约 210 万人受影响 |

数据来自[井水完整研究 Task 3](../bathtub-filter-well-water-research.md)。

### 一个容易被忽略的监管事实

私人井**被明确排除在**联邦《安全饮用水法》(SDWA) 之外——EPA 不检测、不监测、不为私人井设强制标准，也没有任何一次强制检测要求。**责任完全在业主自己。**🟢

这意味着：市政用户每年能收到一份水质报告 (CCR)，而井水用户**除非自己去测，否则可能永远不知道水里有什么。**

## 三、井水问题分两类：一类你察觉得到，一类察觉不到

理解这个区分，比记住任何单个数字都重要。

### A 类 · 感官 / 舒适问题（你自己就会发现）🟢

这些问题**看得到、闻得到、摸得到**——它们会"自己报警"：

- **铁**：橙色 / 锈色的染色（浴缸、水槽、马桶、玻璃门、填缝），金属味，可能让皮肤和头发发干。是美国井水最常见的感官污染物。浓度参考：0.3 ppm 起开始染色和味道；3 ppm 以上是优先处理区。
- **硫化氢**：经典的"臭鸡蛋味"。人能在远低于危害浓度时就闻到——它在变危险之前，早就先变得"没法用"了。约 20% 的井季节性出现。
- **硬度（钙 / 镁）**：皂垢、皮肤紧绷发干、水渍白斑。地下水通常比地表水更硬。
- **沉积物 / pH 偏酸**：颗粒、浑浊；酸性水（<6.5）会腐蚀管件、从管道浸出金属。

### B 类 · 健康问题（没味道、没颜色，你察觉不到）🟢

这是井水最需要认真对待的部分——**它们大多无色无味**，靠感官发现不了：

- **砷**（致癌；新英格兰、上中西部、西南部地质相关）🟢
- **硝酸盐**（农业区、化粪池附近；对婴儿有"蓝婴综合征"风险）🟢
- **细菌 / 大肠杆菌**（化粪池、农业区附近）🟢
- **铀、氡、锰**（区域地质相关；氡在洗澡时的吸入是主要暴露途径）🟢

> **这就是为什么"我家水没味道、看着很清"不等于"我家水没问题"。** 大多数健康级污染物恰恰是无色无味的。

## 四、什么时候你该做一次专业水质检测

一个浴缸滤芯**代替不了**一次真正的水质检测。CDC / EPA 的（自愿）建议是 🟢：

**每年至少测一次：** 总大肠菌群、硝酸盐、总溶解固体 (TDS)、pH

**每 2–3 年（或按当地情况）：** 砷、铀、氡（高风险地区）、挥发性有机物、铅铜铁锰（如果感官上有迹象）、农药 / 除草剂（农业区）

**出现以下情况立即测：**
- 味道、颜色、气味发生变化
- 洪水或附近土地扰动
- 井维修 / 换件之后
- 家里怀孕或有新生儿
- 收到当地水质预警

如果你还没做过一次基线检测，这是比买任何滤芯都更该先做的事。

## 五、KES 浴缸滤芯对井水能做什么、不能做什么（我们把边界说在前面）

KES 是一个**注水阶段的舒适向滤芯**，不是全屋系统、不是水质净化器。对井水，它的适用范围很窄，我们不含糊：

| 井水问题 | KES 能不能管 | 说明 |
|---------|-------------|------|
| 低中度铁（<3 ppm）| ✅ 有界地管 | KDF-85 类媒体针对铁的**nuisance 级**异味 / 锈感；浓度高时滤芯寿命会明显缩短 |
| 硫化氢（臭鸡蛋味）| ✅ 有界地管 | KDF-85 + 催化炭对典型井水浓度的**气味**表现较好 |
| 高铁（>3 ppm）| ❌ 不管 | 滤芯会很快堵塞——**需要全屋反冲洗系统** |
| 硬度 | ❌ 不管 | 没有能有效软化硬水的紧凑型滤材（[井水研究](../bathtub-filter-well-water-research.md) Task 4）|
| **细菌 / 大肠杆菌** | ❌ 不管 | 不是消毒设备，**不认领**杀菌 |
| **砷 / 硝酸盐 / 铀** | ❌ 不管 | 需要全屋 RO 或专用媒体，**不认领** |

### 🔴 我们不说什么（护栏表）

| 我们**不会**说 | 为什么 |
|--------------|--------|
| "井水更脏 / 更危险" / "你的井水有毒" | 不做 toxin-panic / 恐吓。井水不是"更差"，只是**风险类型不同**——重点是"知道你的水" |
| "去除砷 / 硝酸盐 / 细菌" | 无证据、无相应测试；这些需要专业系统，我们**不认领** |
| "净化你的井水 / 让井水安全饮用" | 我们是注水舒适滤芯，不是净水器，不改变饮用安全性 |
| "杀菌 / 消毒" | KDF 只有柱内抑菌属性，不是浴水杀菌；**不得**当消毒claim |
| "软化你的井水" | 紧凑型滤材做不到软化（[claim 台账](../bathtub-filter-claim-register.md) Banned 区）|
| "改善皮肤 / 缓解湿疹" | 疗效属禁区，见 → [E6 洗澡水里的氯值得在意吗](./bathtub-filter-kes-edu-chlorine-skin-worth-it.md) |

核心态度：**不是"井水更差"，而是"先知道你家的水属于哪一类，风险类型不同，工具也不同"。** 高铁、砷、硝酸盐、细菌——这些请找专业系统，我们会诚实劝你去。
