## 一A、B0 测试套装：付费引流品 + 全额返现机制（2026-07-01 拍板）

**一句话**：还没下决心的人先花 `[$9.99]` 买"测你家的水"这个动作；买正式产品时**等额自动抵扣**——测试净成本 $0。

### 为什么这样设计（vs 免费送试纸）

| 维度 | 付费 $9.99 + 返现 | 免费送 |
|---|---|---|
| 线索质量 | 付过钱 = 高意向、真地址 | 撸羊毛/低意向占比高 |
| 成本 | 售价覆盖 COGS+运费 → **合格线索获客成本 ≈ 0** | 每单净亏运费 |
| 心理 | "我投资了验证" → 沉没成本推动完成测试 → 测完自然进转化流 | 收到即忘 |
| 品牌 | **引流品=信任机制本身**（verify-by-user 的付费预演） | 促销感 |

**独有妙处**：别家的引流品是折扣券，KES 的引流品**就是产品哲学**——"先测，再买"。连诚实劝退都被货币化了：氯胺城市用户测完发现 V1 不适合 → 返现码自动转 **V1.5 预售抵扣**（用户没损失、我们收获精准候补）。

### 机制细则

1. **内含**：试纸 ×`[__]` + Before/After 对比卡（见 [proof 页 §四](./bathtub-filter-kes-proof-and-testimonials.md)）+ 读卡说明 + 返现码（印刷或账户自动挂）
2. **返现**：购任一整机 SKU（B1/B2/B4/B5）时**自动全额抵扣**，无需手输；有效期 `[____ 建议 ≥180 天，短期限=变相 scarcity，与品牌冲突]`
3. **劝退转化**：诊断结果=氯胺/井水（未 ship）→ 返现码自动转对应版本预售抵扣 + 候补名单
4. **叠加规则**：与 referral 朋友首单减免、订阅折扣的叠加/互斥 `[____ 待运营]`
5. **措辞合规**：🔴 不说 "FREE test kit"（FTC free 规则：有条件的 free 须显著披露）——说 **"Test first. We'll credit it back."**（诚实且更有品牌味）

> 🟡 待补：定价 `[$9.99?]` 与 COGS/运费核算→财务；返现码技术实现（复用 referral 码系统，见 [归因码节](./bathtub-filter-kes-referral-program.md)）→工程；选购器「未覆盖/不确定」出口挂 B0→产品（见 [选购器 spec](./bathtub-filter-kes-water-match-selector-spec.md)）。

## 二、First-Year Kit 的滤芯数量推导（写出逻辑，数字待定稿）

**推导公式（诚实口径，用 baths 不用月）：**

```
你的年泡澡次数 ≈ 每周泡澡次数 × 52
单套滤芯寿命（baths）= T3 页触发口径（随你家 tap 氯浓度变化）
First-Year Kit 额外滤芯数 = ceil(年泡澡次数 ÷ 单套寿命) − 1   （Starter 已含首套）
```

参照 T3 页 register 原文口径："At 2 ppm tap chlorine, 3 baths/week: soft trigger ≈ 96 baths; mandatory ≈ 121 baths (~9–10 months). At 1 ppm tap: approximately 2× lifespan."（2026-07-02 按 [V1 BOM 表](../bathtub-filter-v1-free-chlorine-removal-dimensions-materials.md) 裁定：寿命数字随模型重算更正）——即**在 2 ppm / 每周 3 次的参照情形下，一套滤芯约覆盖 9–10 个月**；氯更高 / 泡得更勤则需要更多。所以 First-Year Kit 的额外滤芯数**不是拍脑袋的 ×N**，而是按目标客群（首发 P1 城市的典型氯浓度 + 用量假设）算出来的。

> 🟡 **待寿命定稿**：额外滤芯数 ×`[____]` 待 [产品/运营] 在第三方 DPD 寿命曲线（Gate 1）与首发城市典型氯浓度假设定稿后回填；页面文案必带限定句 "Your local tap chlorine affects lifespan — verify with the included free-chlorine test strip."，**不承诺「保证够用一年」**。

## 三、阶梯让利逻辑：为什么多件更便宜（clean-honest 定价叙事）

**我们如实告诉你为什么多件更便宜**——多件省下的是真实成本，我们把它让给你，而不是先虚标一个高价再划掉：

| 省的来源 | 说明 | 让利幅度 |
|---|---|---|
| 包装 | N 件合一盒，包材摊薄 | `[____ 待补]` |
| 物流 | 一次发货 vs N 次发货的运费差 | `[____ 待补]` |
| 获客/交易成本 | 复购单不需要再付一次广告/平台获客成本 | `[____ 待补]` |

对外叙事方向（与 [定价经济学页](./bathtub-filter-kes-pricing-and-refill-economics.md) clean-honest 原则同源）：**价格透明是产品透明的延伸**——"Multipacks cost less because they cost us less to pack, ship, and sell. We pass that on."

- 🔴 **不做虚划线**：不虚标「原价」再划掉制造折扣错觉；多件价与单件价的差 = 上表真实成本差的让利。
- 🔴 **不做 scarcity**：无倒计时、无 "while supplies last"。
- 🔴 **不写 "best value / cheapest"**：触发比价且与 clean-honest 冲突（register 广告行）。

> 🟡 待 [财务] 补：三项成本节省的真实数与让利幅度——**让利幅度须能被上表成本差解释**，这是本页叙事成立的前提。

## 四、一次性多件 vs 订阅：怎么选（诚实指引）

| 你的情况 | 建议 | 为什么 |
|---|---|---|
| 用量稳定、想省心、想按需跳过 | **订阅**（见 [订阅页](./bathtub-filter-kes-refill-subscription.md)） | 订阅价 `[____ 待补]` 通常低于多件均摊 `[____ 待补]`，且有 Skip-if-still-good 机制：试纸测到还达标就跳过 |
| 不想绑定任何自动扣款、用量可预测 | **Refill 多件装（B3）** | 一次买清，无订阅关系 |
| 低频使用 / 低氯地区（寿命更长） | **单件或 ×2**，别囤 | 滤芯寿命随氯浓度与用量变（T3）；囤多了没意义——我们不劝你多买 |
| 第一次买、还没验证自家水 | **先 Starter（B1）**，别直接上 First-Year Kit | 先用试纸验证有效、确认适配，再决定囤不囤 |

per-bath 成本对比框架见 [SVC7 定价经济学页](./bathtub-filter-kes-pricing-and-refill-economics.md)（数字待补后两页同步）。
