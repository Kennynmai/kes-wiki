# 买后验证流程（Post-Purchase Verification）

## 这一页是什么

这是**买后**的信任页：你装好滤芯后，**怎么自己测一次、确认它真的在工作**。KES 的诚实定位靠这一步兑现——**「测得到 / 自己测」不是口号，是你亲手做的动作**。

> **口径纪律**：本页验证方法以 [claim-register](../bathtub-filter-claim-register.md) 与 [T1 自测页](./bathtub-filter-kes-page-water-test-diagnosis.md) 为准，不新造去氯数字。referral 漏斗承接 [获客引擎 §五 / §七](../bathtub-filter-kes-water-diagnosis-kit-and-modular-acquisition-engine.md)，但**具体时序 / 奖励为 [____ 待补]**（见 §四）。每条标 🟢 / 🟡 / 🔴。

**承重口径（照 register「Verification-by-user」Allowed 行原文保留英文）：**

> "Verify with the included free-chlorine test strip: compare before- and after-filter water. **Do not use a TDS pen — this product does not target TDS.**"

---

## 一、买了 → 怎么自测确认有效（前后对比走查）

游离氯版用**游离氯试纸**做「装芯前 vs 装芯后」对比——看游离氯从进水到出水降下来。🟢

```
步骤                                 你会看到
──────────────────────────────────────────────────────────
① 装芯前：接一杯直接从龙头出的水      → 游离氯试纸垫显色（有氯的底色）
② 用游离氯试纸测这杯「前」水          → 记下档位（粗筛档，非实验室数字）
③ 装上滤芯，正常注水，接一杯「后」水  → 从滤芯出来的水
④ 用同批试纸测「后」水                → 档位明显下降 = 滤芯在去游离氯
⑤ 前 vs 后并排对比                    → 「你自己看到氯降下来了」= 信任锚
```

- **验证试纸必须匹配配方**：游离氯版 → **游离氯试纸**（[获客引擎 §五](../bathtub-filter-kes-water-diagnosis-kit-and-modular-acquisition-engine.md)）。氯胺版要用**总氯试纸**——游离氯试纸测不出氯胺（V1.5 上线时另行说明）。
- **粗筛指路 ≠ 实验室**：试纸给档位，不给精确 mg/L；我们说「你看到它在工作」，不冒充实验室（照 register「A quick guide, not a lab test.」）。🟡

> 🔴 **禁 TDS 笔验证**：TDS 测总溶解固体，非氯（register Banned）。用 TDS 笔会误导——本产品不以 TDS 为目标，装了阻垢 TDS 甚至可能略升。

---

## 二、试纸怎么读（读数纪律）

- **对着自然光、按说明书的显色等待时间读**——不同垫子等待时间不同，读早读晚都会偏。🟢
- **前后用同一批、同一时间读**，才可比。
- **档位下降**就是有效信号；不必纠结绝对数字（粗筛工具的本分）。
- ⚠️ **抗坏血酸干扰时机**（氯胺版相关）：刚加完维C / 抗坏血酸钠立即测，残余还原剂会让读数偏低、**高估效果**——须按说明书指引的时机测，否则自测会误判（[获客引擎 §五](../bathtub-filter-kes-water-diagnosis-kit-and-modular-acquisition-engine.md)）。🟡（V1.5 相关，游离氯版 V1 不涉及）

> 读数只说「水的类型 / 滤芯是否在工作」，**不导向 toxin-panic / 健康恐吓**（register Banned）。

## 三、什么时候该换芯（验证也是复购触发）

复购不靠黑箱倒计时，靠**你自己测到该换了**。🟢

- 游离氯试纸「后」水**第一次显出零以上的色阶** → 该换芯（这是试纸能读出的唯一可靠触发；不要等它接近「前」水）。
- 具体更换触发口径（soft / strong / mandatory 门槛、baths / gallons 换算）**不在本页新造**——见 [T3 更换与寿命页](./bathtub-filter-kes-page-replacement-and-lifespan.md)。
- 寿命受你家 tap 游离氯浓度影响，随行「your local tap chlorine affects lifespan — verify with test strip」。

## 四、什么时候收到 referral 邀请（漏斗来自获客引擎）

**验证成功那一刻是信任峰值，也是最该邀请你分享的一刻**——你刚亲眼自证产品有效（[获客引擎 §七 7.2](../bathtub-filter-kes-water-diagnosis-kit-and-modular-acquisition-engine.md)）。机制真理源在 [推荐计划页](./bathtub-filter-kes-referral-program.md)。

**已定的机制方向（🟢 承接获客引擎）：**
- 触发点：诊断后（中）/ 拆箱卡·订单确认邮件（中）/ **★ 自测验证后（最高，信任峰值）**。
- 载体：可分享的「你家的水」结果卡（带推荐人码唯一链接）。
- 奖励挂**复购**（下一支滤材 / 模块），不挂现金。

**待补的具体数字 / 时序（🟡）：**

- 何时触发验证后邀请：**归 [邮件生命周期 spec E3（T+10–14，T+0=妥投日）](./bathtub-filter-kes-email-lifecycle-spec.md) 唯一定义**——本页只引用不定义（2026-07-02 收编）；站内即时弹层 vs 邮件的分工细节在该页 E3 行。
  > 邮件时序唯一 owner = [SVC11 邮件生命周期 spec](./bathtub-filter-kes-email-lifecycle-spec.md)（此前本页与 referral 页循环引用，已收编）。
- 推荐人奖励：`[____ 待补]`（下次换芯 $X off？满 N 人送一支？）
  > 🟡 待 [运营] 补：具体奖励额度 / 门槛——本页定稿前不对外承诺数字。
- 被推荐朋友的首单激励：`[____ 待补]`（首单折扣？免费诊断套件？）
  > 🟡 待 [运营] 补：朋友端激励形式与额度。
- referral 计划是否纳入 V1 首发：`[____ 待补]`
  > 🟡 待 [市场/运营] 补：与 [推荐计划页](./bathtub-filter-kes-referral-program.md) 同步——首发开还是 post-launch 再开。

## 五、承重护栏（本页红线）

1. **验证工具 = 匹配配方的试纸** —— 游离氯版用游离氯试纸；🔴 禁 TDS 笔、禁铅试纸。
2. **粗筛 ≠ 实验室** —— 试纸给档位不给精确数字，说「你看到它在工作」。
3. **不新造去氯 / 寿命数字** —— 引 T3，不在本页造曲线。
4. **referral 文案不 toxin-panic / 不健康声称 / 不软化承诺** —— framing = 「分享给用同样水的人」，不刷屏、不绑夸大（register Banned + 获客引擎 §7.7）。
5. **抗坏血酸干扰时机提示**（氯胺版）—— 按指引时机测，否则高估效果。

> 完整台账见 [claim-register](../bathtub-filter-claim-register.md)。
